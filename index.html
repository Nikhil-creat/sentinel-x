    CNN lab: see malware as an image

    Security researchers turn a file's bytes into a grayscale picture, then let a convolutional network recognise the texture of each malware family. Generate a sample or drop in any file from your device.

    Files are read in your browser. They are only sent anywhere if you connect your own backend below.

    Family probabilities

    The page runs a lightweight feature-based stand-in (byte entropy and repetition patterns) so the demo works offline. With the Docker backend connected, files go to the vision service, which can serve a trained PyTorch CNN.

    RAG: answers grounded in threat intelligence

    Ask a security question. Sentinel-X retrieves the most relevant knowledge chunks, writes an answer from them and cites every source. When nothing relevant exists, it says so instead of guessing.

      Retrieval uses TF-IDF similarity. The upgrade path is embeddings in a vector database with a reranker. Retrieved text is treated as data, never as instructions.

      Built to be trusted

      A security tool that uses AI must be secure and accountable itself. These are the rules the design follows.

      Securing the system

      • Least privilege. Containers run as non-root with a read-only filesystem and no extra capabilities.
      • Segmented networks. Analysis services have no route to the internet or the outside world.
      • Gateway controls. Optional API key, rate limiting, upload limits and security headers.
      • Strict browser policy. The web container sends a content security policy and other hardening headers.
      • Audit trail. Every agent step and tool call is recorded in the run timeline.

      Using AI responsibly

      • Prompt-injection defense. Retrieved text and log lines are data. Tools are allow-listed.
      • Human in the loop. Containment needs approval by default and runs in dry-run mode.
      • Grounded answers. Claims cite sources, and unsupported questions are refused.
      • Explainable verdicts. The CNN lab shows where it looked, and findings list their evidence.
      • Privacy first. The browser demos send nothing anywhere, and the LLM can run locally.

      Roadmap

      1. Foundation

        Log ingestion, event schema, dashboard and the Docker base with hardened containers.

      2. Intelligence

        Train the CNN on public malware image datasets and move retrieval to embeddings in a vector database.

      3. Autonomy

        Connect a local LLM and agents with tool policies, approval gates and audit logging.

      4. Hardening

        Red-team the agents, evaluate accuracy and grounding, and add Kubernetes deployment.

      Next horizon

      Planned research directions, not yet built.

      Federated learning

      Train the CNN across sites without sharing raw files.

      Post-quantum readiness

      Inventory cryptography and prepare migration to quantum-safe algorithms.

      On-device LLM

      Run a small model in the browser with WebGPU for fully private analysis.

      Edge sensors

      Deploy lightweight agents on Raspberry Pi and Jetson class devices.

      Attack-path graphs

      Model assets and permissions as a graph to predict lateral movement.

      Automated red team

      Continuously attack the agents with prompt-injection suites and score their defenses.
